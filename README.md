2.Objectives
To analyze the effectiveness of naïve prompting (vague, unstructured queries) versus basic prompting (clear, structured, detailed queries).

To evaluate ChatGPT’s response quality, accuracy, and depth under both prompting conditions.

To demonstrate the role of prompt engineering in improving the reliability of AI-generated outputs.

To provide insights and guidelines for best practices in interacting with large language models (LLMs).

Methodology 3.1 Prompt Categories
The experiment involves designing test cases across diverse scenarios such as:

Concept Explanation (e.g., overloading vs overriding in Java)

Problem-Solving (e.g., SQL queries, C programming logic)

Creative Tasks (e.g., story generation, UX design comparison)

Analytical Tasks (e.g., comparative analysis, report writing)

Mathematical/Logical Problems (e.g., percentage calculations, algorithms)

3.2 Prompt Types

Naïve Prompting: Short, vague, or ambiguous queries such as “Explain Java overloading” or “Write SQL for employees salary”.

Basic Prompting: Structured, specific, and detailed queries such as “Explain overloading and overriding in Java with definitions, key differences, and working code examples, followed by a real-world analogy.”

3.3 Evaluation Parameters

Each response will be evaluated using the following metrics:

Clarity – Is the response structured and easy to understand?

Accuracy – Are the facts and outputs correct?

Depth – Does the answer go beyond surface-level explanation?

Relevance – Does it directly address the user’s need?

Usefulness – Can the response be practically applied?

Hypothesis
Naïve Prompts: Likely to generate general, less structured, and sometimes incomplete responses.

Basic Prompts: Expected to yield accurate, structured, and detailed outputs with higher contextual relevance.

Expected Outcomes
Basic prompting significantly improves the quality and precision of ChatGPT’s responses.

Naïve prompting may still produce acceptable outputs but often requires user interpretation, refinement, or follow-up questions.

Clear evidence that prompt engineering acts as a multiplier in extracting maximum value from AI systems.
